# Expense Tracker 💰📊

A modern full-stack Expense Tracker web application built using the MERN Stack.  
This application helps users manage daily expenses with powerful analytics, authentication, charts, export features, and a professional dashboard UI.

---

## 🚀 Features

### 🔐 Authentication System
- User Registration
- User Login
- JWT Authentication
- Protected Routes
- Persistent Login Sessions
- Secure Dashboard Access

---

### 💵 Expense Management
- Add Expenses
- Edit Expenses
- Delete Expenses
- Search Expenses
- Filter by Category
- Real-Time Expense Updates

---

### 📈 Analytics Dashboard
- Expense Pie Chart
- Weekly Expense Analytics
- Monthly Expense Analytics
- Date-Based Tracking
- Interactive Graphs
- Total Expense Summary
- Weekly & Monthly Reports

---

### 📄 Export Features
- Download PDF Reports
- Export CSV Files

---

### 🎨 UI/UX
- Responsive Design
- Sticky Sidebar Navigation
- Modern Dashboard Layout
- Dark Theme UI
- Smooth User Experience

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/DEV0018/expense-tacker.git
```

---

### 2️⃣ Install Backend Dependencies

```bash
cd backend
npm install
```

---

### 3️⃣ Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

---

## 🔑 Environment Variables

Create a `.env` file inside backend folder:

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
PORT=5000
```

---

## ▶️ Run Backend

```bash
cd backend
npm run dev
```

Backend runs on:

```bash
http://localhost:5000
```

---

## ▶️ Run Frontend

```bash
cd frontend
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```
